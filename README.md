# SuRoom
A CS310 project that finds empty rooms in Sabanci University

Version : Flutter 3.47.5

# Run Instructions:

1. Clone the repository:
```
git clone <https://github.com/haneskicioglu/SuRoom>
cd <SuRoom>
```
 
2. Install dependencies:
```
flutter pub get
```
 
3. List available devices:
```
flutter devices
```
 
4. Run the app:
```
flutter run
```
